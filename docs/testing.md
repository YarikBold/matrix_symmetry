# План тестирования

## Цель тестирования

Цель тестирования — проверить правильность определения симметричности квадратной матрицы и корректность работы функции `is_symmetric()`.

## Средства тестирования

Для автоматического тестирования используется стандартный модуль Python `unittest`.

Тесты находятся в файле:

```text
tests/test_main.py
```

## Тестовые случаи

### Тест 1. Симметричная матрица

Входные данные:

```text
[[1, 2],
 [2, 3]]
```

Ожидаемый результат: `True`.

### Тест 2. Несимметричная матрица

Входные данные:

```text
[[1, 2],
 [3, 4]]
```

Ожидаемый результат: `False`.

### Тест 3. Матрица размером 1 × 1

Входные данные:

```text
[[5]]
```

Ожидаемый результат: `True`.

### Тест 4. Матрица с вещественными числами

Входные данные:

```text
[[1.5, 2.7],
 [2.7, -3.2]]
```

Ожидаемый результат: `True`.

### Тест 5. Нулевая матрица

Входные данные:

```text
[[0, 0],
 [0, 0]]
```

Ожидаемый результат: `True`.

## Запуск тестов

Локальный запуск выполняется командой:

```bash
python -m unittest discover -s tests -v
```

## Автоматическое тестирование

При отправке изменений в ветки `main` или `develop` GitHub Actions автоматически выполняет проверку исходного кода с помощью `flake8` и запускает автоматические тесты.

Успешное выполнение всех тестов подтверждается итоговым сообщением `OK`.

### План проверки

1. Запустить исходные тесты и зафиксировать покрытие.

3. Проверить выходные сообщения, преобразование JSON, команду запуска

4. Проверить обмен через командную строку и сохранность входного файла.
5. Повторить прогон с измерением строк и ветвей и провести инспекцию кода.

### Проверки «белого ящика»

В `print_result()` проверены оба исхода решения о симметричности. В
`map_request()` проверено выражение `not isinstance(values, list) or len(values) != n`.
Для размера 1 условие A означает, что `values` не является списком, а условие B
означает, что его длина отличается от 1.

| Вход | A | B | Решение и фактический результат |
|---|---|---|---|
| `""` | Истина | Истина | Запрос отклонён |
| `"x"` | Истина | Ложь | Запрос отклонён |
| `[]` | Ложь | Истина | Запрос отклонён |
| `[["7"]]` | Ложь | Ложь | Получена матрица `[[7.0]]` |

При истинном A Python не вычисляет B. В двух первых строках таблицы
значение B характеризует входные данные. При ложном A условие B
вычисляется и принимает оба значения.

### Интеграционные сценарии

| Сценарий | Ожидаемое поведение | Фактический результат |
|---|---|---|
| Корректный запрос с симметричной или несимметричной матрицей | Код 0, файл ответа с тем же `request_id`, числовым размером и логическим результатом | Для двух запросов получены ожидаемые ответы |
| Некорректный JSON, неверный размер или элемент | Сообщение об ошибке и код 1 | Ошибка зафиксирована, файл ответа не создан |
| Недоступный процесс или таймаут | Соответствующее сообщение об ошибке и код 1 | Сообщение получено, файл ответа не создан |
| Совпадающие пути запроса и ответа | Код 1 и сохранение входного файла | Подтверждено тестом и командой `cmp` после исправления BR-01 |
