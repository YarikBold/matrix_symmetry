# План тестирования

## Цель тестирования

Цель тестирования — проверить правильность определения симметричности квадратной матрицы и корректность работы функции `is_symmetric()`.

## Средства тестирования

Для автоматического тестирования используется стандартный модуль Python `unittest`.

Тесты находятся в файле:

```text
tests/test_main.py
```

## Тестовые случаи

### Тест 1. Симметричная матрица

Входные данные:

```text
[[1, 2],
 [2, 3]]
```

Ожидаемый результат: `True`.

### Тест 2. Несимметричная матрица

Входные данные:

```text
[[1, 2],
 [3, 4]]
```

Ожидаемый результат: `False`.

### Тест 3. Матрица размером 1 × 1

Входные данные:

```text
[[5]]
```

Ожидаемый результат: `True`.

### Тест 4. Матрица с вещественными числами

Входные данные:

```text
[[1.5, 2.7],
 [2.7, -3.2]]
```

Ожидаемый результат: `True`.

### Тест 5. Нулевая матрица

Входные данные:

```text
[[0, 0],
 [0, 0]]
```

Ожидаемый результат: `True`.

## Запуск тестов

Локальный запуск выполняется командой:

```bash
python -m unittest discover -s tests -v
```

## Автоматическое тестирование

При отправке изменений в ветки `main` или `develop` GitHub Actions автоматически выполняет проверку исходного кода с помощью `flake8` и запускает автоматические тесты.

Успешное выполнение всех тестов подтверждается итоговым сообщением `OK`.
