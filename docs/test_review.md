# Ревью тестов ЛР № 4

Проверены новые модульные, интеграционные и регрессионные проверки,
`pytest.ini` и настройки `.github/workflows/integration.yml`.

| Критерий | Результат ревью |
|---|---|
| Проверяемые границы | Размеры и длины строк проверяются соседними значениями, равенство чисел — соседними значениями `float` |
| Независимость случаев | Файлы запросов и ответов создаются через `tmp_path`, подмены входа и процесса ограничены одной проверкой |
| Проверка результата | Для файлового режима проверяются код завершения, поля ответа и сохранность байтов входного файла |
| Регрессия BR-01 | Проверены совпадающий путь и два разных имени одного файла. Обе проверки защищают исходный запрос |
| Воспроизводимость | Зависимости закреплены. Запуск скрипта ограничен по времени, а файлы получаются из конкретного коммита |
| Автоматический запуск | Маркер `regression` зарегистрирован. Регрессия и полный набор запускаются в CI, результаты сохраняются в XML |

Проверка жёсткой ссылки зависит от её поддержки на файловой системе.
Она пройдена локально на Windows и в GitHub Actions на Ubuntu.
Ревью завершилось успешным запуском 4 регрессионных тестов и полного
набора из 51 теста и 30 подтестов. flake8 сообщил о нуле замечаний.
