# Результаты код-ревью

Код-ревью проекта выполнено самостоятельно в рамках лабораторной работы № 2.

В ходе ревью были проверены следующие файлы проекта:

Цель код-ревью заключалась в проверке структуры программы, корректности реализации алгоритма, обработки ошибочных ситуаций, качества исходного кода, автоматических тестов и настройки CI.

## Проверка исходного кода

Основной исходный код программы расположен в файле `src/main.py`.

Программа разделена на несколько функций, каждая из которых выполняет отдельную задачу:

- `input_size()` — запрашивает размерность квадратной матрицы и проверяет корректность введённого значения;
- `input_matrix(n)` — выполняет ввод элементов матрицы и проверяет корректность введённых данных;
- `is_symmetric(matrix)` — определяет, является ли матрица симметричной относительно главной диагонали;
- `print_result(result)` — выводит результат проверки матрицы;
- `main()` — управляет последовательностью выполнения программы.

Такое разделение делает структуру программы понятной и позволяет отдельно проверять основные части программы.

Функция `is_symmetric(matrix)` реализует алгоритм проверки симметричности квадратной матрицы. Для выполнения проверки сравниваются элементы, расположенные симметрично относительно главной диагонали.

Для уменьшения количества сравнений рассматриваются только элементы, расположенные выше главной диагонали, и соответствующие им элементы ниже диагонали.

Если обнаружена хотя бы одна пара несовпадающих элементов, функция возвращает значение `False`. Если все проверяемые пары равны, функция возвращает значение `True`.

## Проверка обработки некорректных данных

В ходе ревью была проверена обработка ошибочных входных данных.

Программа предусматривает обработку следующих ситуаций:

- ввод неположительной размерности матрицы;
- ввод значения размерности, которое невозможно преобразовать в целое число;
- ввод неверного количества элементов в строке матрицы;
- ввод элементов матрицы, которые невозможно преобразовать в числа.

При возникновении ошибки программа выводит соответствующее сообщение и повторно запрашивает ввод данных.

## Проверка автоматических тестов

Автоматические тесты расположены в файле `tests/test_main.py`.

Для тестирования используется стандартный модуль Python `unittest`.

В проекте реализовано пять автоматических тестов:

1. Проверка симметричной матрицы.
2. Проверка несимметричной матрицы.
3. Проверка матрицы размером `1 × 1`.
4. Проверка симметричной матрицы с вещественными числами.
5. Проверка нулевой матрицы.

Локальный запуск тестов выполнялся командой:

```bash
python -m unittest discover -s tests -v
```

В результате выполнения все пять тестов завершились успешно. Итоговое сообщение программы тестирования:

```text
OK
```

```bash

```

После выполнения команды сообщения об ошибках и нарушениях не были выведены.

Таким образом, проверяемые файлы `src/main.py` и `tests/test_main.py` успешно прошли проверку `flake8` с установленной максимальной длиной строки 100 символов.


Workflow GitHub Actions был запущен после отправки изменений в ветку `main`.

Все этапы workflow завершились успешно. GitHub Actions отобразил успешный статус выполнения job `test`.
