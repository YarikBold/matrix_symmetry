# Протокол граничного тестирования

Лабораторная работа № 4, уровень 1, вариант 3. Проект `matrix_symmetry`.
Исходная версия: `4826121`, тег `v1.0.0`. Среда: Windows, Python 3.11.6,
pytest 9.2.0, coverage.py 7.17.1. Порог покрытия проекта — 80 %.

Границы выбраны по трём правилам программы: размер матрицы больше нуля,
длина строки равна размеру матрицы, а симметричные элементы точно равны.
Около границы равенства использованы соседние значения `float`.

| № | Проверка | Входные данные | Ожидаемый результат | Фактический результат | Вердикт |
|---:|---|---|---|---|---|
| 1 | Размер ниже границы | `-1`, затем `1` | Сообщение о положительном размере и повторный ввод | Сообщение выведено, возвращено `1` | Пройден |
| 2 | Нулевой размер | `0`, затем `1` | Сообщение о положительном размере и повторный ввод | Сообщение выведено, возвращено `1` | Пройден |
| 3 | Минимальный допустимый размер | `1` | Принять размер без ошибки | Возвращено `1`, сообщения нет | Пройден |
| 4 | Следующий допустимый размер | `2` | Принять размер без ошибки | Возвращено `2`, сообщения нет | Пройден |
| 5 | Строка короче на один элемент | Размер 2, строки `1`, `1 2`, `2 3` | Отклонить короткую строку и повторить ввод | Сообщение выведено, получена `[[1.0, 2.0], [2.0, 3.0]]` | Пройден |
| 6 | Строка длиннее на один элемент | Размер 2, строки `1 2 3`, `1 2`, `2 3` | Отклонить длинную строку и повторить ввод | Сообщение выведено, получена `[[1.0, 2.0], [2.0, 3.0]]` | Пройден |
| 7 | Пустая матрица | `[]` | Исключение `ValueError` | Получено исключение о непустом списке | Пройден |
| 8 | Матрица 1×1 | `[[0.0]]` | `True` | `True` | Пройден |
| 9 | Соседнее значение ниже равенства | `[[0.0, 1.0], [nextafter(1.0, 0.0), 0.0]]` | `False` | `False` | Пройден |
| 10 | Точное равенство | `[[0.0, 1.0], [1.0, 0.0]]` | `True` | `True` | Пройден |
