# Результаты интеграционного тестирования

## Методика

Программа запускается отдельным процессом:
python -m src.main.

Запросы и ответы создаются во временной папке.
Проверяются коды завершения, содержимое JSON-ответа,
типы полей и обработка ошибок.
Временная папка удаляется после выполнения тестов.

## Сценарии и результаты

| Метод | Сценарий | Результат |
| --- | --- | --- |
| test_file_exchange | Симметричная и несимметричная матрицы | Код 0, правильный ответ и типы полей |
| test_invalid_json | Повреждённый JSON | Код 1, сообщение в stderr, ответ не создан |
| test_invalid_matrix | Неверная форма, текст, inf | Код 1, сообщение в stderr, ответ не создан |
| test_missing_input | Входной файл отсутствует | Код 1, сообщение в stderr, ответ не создан |
| test_incomplete_arguments | Указан только --input | Код 2, сообщение в stderr, ответ не создан |
| test_interactive_mode | Запуск без параметров | Код 0, правильный результат в консоли |

Всего: 6 тестовых методов, 9 сценариев с учётом subTest.

## Запуск интеграционных тестов

python -m unittest discover -s tests -p "test_integration.py" -v

Фактический результат: Ran 6 tests, OK.

## Запуск всех тестов

python -m unittest discover -s tests -v

Фактический результат: Ran 13 tests, OK.

## Вывод

Проверена цепочка чтения JSON, преобразования данных,
вычислений и сохранения ответа.
Ошибочные запросы приводят к ненулевому коду завершения.
Интерактивный режим и предыдущие тесты работают успешно.
