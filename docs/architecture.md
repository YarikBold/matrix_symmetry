# Архитектура проекта

## Назначение программы

Программа предназначена для определения симметричности квадратной вещественной матрицы относительно главной диагонали.

## Основные функции программы

Программа состоит из следующих функций:

- input_size() — ввод и проверка размерности матрицы;
- input_matrix(n) — ввод элементов квадратной матрицы;
- is_symmetric(matrix) — проверка симметричности матрицы относительно главной диагонали;
- print_result(result) — вывод результата проверки;
- main() — управление последовательностью выполнения программы.

## Логика работы

После запуска программа запрашивает размерность квадратной матрицы и её элементы. Затем функция is_symmetric() сравнивает элементы, расположенные симметрично относительно главной диагонали.

Для проверки достаточно сравнивать элементы выше главной диагонали с соответствующими элементами ниже неё.

Если все пары совпадают, матрица считается симметричной. При обнаружении несовпадения программа определяет матрицу как несимметричную.

## Автоматизация

Для автоматической проверки проекта используется GitHub Actions.

CI выполняет:

- получение исходного кода;
- установку Python 3.11;
- установку flake8;
- проверку исходного кода линтером;
- запуск автоматических тестов.
