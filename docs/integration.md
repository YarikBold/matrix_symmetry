# Интеграция модулей

## Проект и стратегия

Вариант 3. Сохранена предметная область ЛР 1 и ЛР 2:
проверка симметричности матрицы.

Стратегия — сэндвич-интеграция.
Внутренние модули взаимодействуют прямыми вызовами функций.
На уровне 2 дополнительно реализован обмен JSON-файлами.

## Архитектура

- input_module.py — интерактивный ввод.
- processing_module.py — проверка матрицы и симметричности.
- output_module.py — вывод результата в консоль.
- json_transport.py — чтение, преобразование и запись JSON.
- main.py — управление и выбор режима.

## Потоки данных

Интерактивный режим:
Пользователь -> input_module -> main -> processing_module
-> main -> output_module -> Пользователь.

Файловый режим:
JSON-запрос -> load_request -> map_request -> run_json
-> is_symmetric -> make_response -> save_response -> JSON-ответ.

Результат также передаётся в output_module для вывода в консоль.

## Структуры данных

Запрос — JSON-объект с версией, идентификатором,
размером и строками матрицы.

Внутренний словарь:
request_id: str, n: int, matrix: list[list[float]].

Вычислительный модуль принимает matrix и возвращает bool.
Модуль вывода принимает логический результат.

## Сопоставление полей

| Поле запроса | Внутреннее поле | Преобразование |
| --- | --- | --- |
| version | PROTOCOL_VERSION | Проверка версии 1.0 |
| request_id | request_id | Проверка непустой строки |
| dimension | n | Строка или целое число -> int |
| values | matrix | Проверка квадратной структуры |
| values[i][j] | matrix[i][j] | Строка или число -> float |

| Внутреннее значение | Поле ответа | Тип |
| --- | --- | --- |
| PROTOCOL_VERSION | version | str |
| request_id | request_id | str |
| n | size | int |
| Результат проверки | is_symmetric | bool |

## Формат обмена

JSON, кодировка UTF-8, версия формата 1.0.
Входной файл также допускает UTF-8 с BOM.
Ответ записывается с отступами, без экранирования кириллицы.

## Пример запроса

    {
      "version": "1.0",
      "request_id": "matrix-001",
      "dimension": "2",
      "values": [["1", "2"], ["2", "3"]]
    }

## Пример ответа

    {
      "version": "1.0",
      "request_id": "matrix-001",
      "size": 2,
      "is_symmetric": true
    }

## Запуск

Интерактивный режим:
python src/main.py

Файловый режим:
python src/main.py --input examples/matrix_request.json --output examples/matrix_response.json

Параметры --input и --output указываются вместе.

## Проверки и ошибки

Проверяются версия, идентификатор, размер, количество строк
и элементов, типы данных и конечность чисел.

Коды завершения:
- 0 — успешная обработка;
- 1 — ошибка чтения, данных, вычислений или записи;
- 2 — неверные параметры командной строки.

В файловом режиме сообщения об ошибках направляются в stderr.

## Дополнение для уровня 3

В файловом режиме вычисления выполняются отдельным процессом.

Актуальный поток:
JSON-запрос -> json_transport -> main.run_json
-> integration_service.check_matrix -> processing_worker
-> processing_module.is_symmetric -> результат bool
-> json_transport -> JSON-ответ и вывод в консоль.

Между процессами матрица и результат передаются как JSON
через стандартные потоки ввода и вывода.

Параметр --timeout задаёт время ожидания в секундах.
Значение по умолчанию — 5 секунд.
Допускается только положительное конечное значение.

Обрабатываются таймаут, недоступность вычислительного процесса,
неправильный ответ процесса, некорректные данные и версия запроса.

При ошибке возвращается код 1.
Если файл ответа существовал до ошибки, он может сохраниться;
результат запуска необходимо оценивать по коду завершения.
