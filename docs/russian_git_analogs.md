# Обзор российских аналогов Git

## Введение

В рамках лабораторной работы рассмотрены российские программные платформы, предназначенные для хранения исходного кода, управления Git-репозиториями и организации процессов совместной разработки.

Для обзора выбраны следующие решения:

- GitFlic;
- GitFlame;
- Deckhouse Code.

Все рассмотренные продукты поддерживают работу с Git и могут использоваться как инструменты организации разработки программных проектов.

## GitFlic

### Назначение

GitFlic — российская DevOps-платформа для хранения исходного кода и совместной разработки программных проектов.

Платформа позиционируется как российская альтернатива GitLab и может использоваться как в облачном варианте, так и при локальном развёртывании.

### Функциональные возможности

GitFlic предоставляет возможности:

- хранения Git-репозиториев;
- работы с ветками;
- совместной разработки;
- управления изменениями проекта;
- организации процессов DevOps;
- использования облачного или локального варианта развёртывания.

### Преимущества

К преимуществам GitFlic можно отнести:

- российское происхождение платформы;
- поддержку стандартного Git;
- возможность локального развёртывания;
- наличие инструментов совместной разработки;
- возможность использования в качестве альтернативы зарубежным Git-сервисам.

### Ограничения

При использовании GitFlic необходимо учитывать, что набор функций и интерфейс могут отличаться от зарубежных платформ, поэтому при переходе с GitHub или GitLab может потребоваться дополнительное изучение возможностей сервиса.

В Едином реестре российского программного обеспечения GitFlic указан под номером 15861.

## GitFlame

### Назначение

GitFlame — российский сервис хранения репозиториев с системой версионного контроля исходного кода.

Платформа предназначена для разработчиков и DevOps-инженеров и построена на системе контроля версий Git.

### Функциональные возможности

GitFlame позволяет:

- создавать и хранить Git-репозитории;
- вести историю изменений исходного кода;
- работать с версиями проекта;
- использовать стандартные механизмы Git;
- организовывать работу разработчиков с исходным кодом.

### Преимущества

К преимуществам GitFlame относятся:

- использование стандартной системы Git;
- российское происхождение решения;
- возможность применения для хранения и контроля версий исходного кода;
- привычный для разработчиков подход к работе с репозиториями.

### Ограничения

По сравнению с более крупными платформами набор дополнительных DevOps-инструментов и интеграций может отличаться, поэтому при выборе платформы необходимо учитывать требования конкретного проекта.

В Едином реестре российского программного обеспечения GitFlame указан под номером 21590.

## Deckhouse Code

### Назначение

Deckhouse Code — российское решение для непрерывной разработки и управления жизненным циклом программного обеспечения.

Платформа предоставляет инструменты для хранения исходного кода и организации процессов CI/CD.

### Функциональные возможности

Deckhouse Code предоставляет:

- хранение исходного кода;
- работу с Git-репозиториями;
- инструменты непрерывной интеграции;
- инструменты непрерывной доставки;
- средства управления жизненным циклом программного проекта.

### Преимущества

К преимуществам Deckhouse Code можно отнести:

- поддержку Git;
- наличие встроенных средств CI/CD;
- ориентацию на полный жизненный цикл программного обеспечения;
- возможность применения в DevOps-процессах.

### Ограничения

Платформа ориентирована не только на хранение Git-репозиториев, но и на комплексные процессы разработки и DevOps. Поэтому для небольших учебных проектов часть возможностей может оказаться избыточной.

В Едином реестре российского программного обеспечения Deckhouse Code указан под номером 27871.

## Вывод

Рассмотренные российские платформы используют Git и предназначены для организации хранения исходного кода и совместной разработки.

GitFlic является полноценной DevOps-платформой и может использоваться как российская альтернатива GitLab.

GitFlame ориентирован прежде всего на хранение Git-репозиториев и контроль версий исходного кода.

Deckhouse Code ориентирован на более комплексное управление процессами разработки и включает инструменты CI/CD.

Выбор конкретной платформы зависит от требований проекта, необходимого набора DevOps-инструментов и условий развёртывания.
