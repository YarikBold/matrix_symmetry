# План интеграции

Проект: проверка симметричности матрицы.
Стратегия: сэндвич-интеграция.

## Состав модулей

- input_module.py — ввод размера и элементов матрицы.
- processing_module.py — проверка симметричности.
- output_module.py — вывод результата.
- main.py — управление последовательностью действий.

## Интерфейсы

- input_size() -> int: положительный размер матрицы.
- input_matrix(n) -> list[list[float]]: квадратная матрица.
- is_symmetric(matrix) -> bool: результат проверки.
- print_result(result) -> None: вывод сообщения.

На уровне 1 данные передаются прямыми вызовами функций.

## Схема взаимодействия

Пользователь -> input_module -> main
main -> processing_module -> main
main -> output_module -> Пользователь

## Порядок интеграции

1. Проверить нижний вычислительный модуль тестовым драйвером.
2. Соединить управляющий модуль с вводом и выводом,
   временно заменив вычислительный модуль заглушкой.
3. Заменить заглушку реальным вычислительным модулем.
4. Проверить работу всей программы и обработку ошибок.

## Обоснование стратегии

Сэндвич-интеграция позволяет отдельно проверить управление
программой и вычисления, затем объединить их через заданный
интерфейс. Драйвер вызывает вычислительный модуль на тестовых
данных, а заглушка возвращает заранее заданный результат.

## Проверки

Симметричная и несимметричная матрицы, матрица 1x1,
нулевая матрица, дробные числа, неверный размер,
неверное количество элементов строки и нечисловой ввод.
