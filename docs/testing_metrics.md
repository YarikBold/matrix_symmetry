## Дефект и его плотность

За работу найден и исправлен один уникальный дефект
[BR-01](bug_reports.md). Для расчёта взята версия `21e02dd`, на которой
дефект воспроизводится. В файлах `src/*.py` этой версии насчитано
255 непустых строк, исключая строки, начинающиеся с комментария.

Плотность обнаруженных дефектов: 1 × 1000 / 255 = **3,92 дефекта на 1000 строк**.
Повторные воспроизведения BR-01 в количестве дефектов учитываются один раз.

## Время обнаружения в контрольном прогоне

Для каждого замера на Windows создан свежий экземпляр запроса из коммита
`21e02dd`. Отсчёт `perf_counter()` начинался непосредственно перед запуском
`src/main.py` с одним путём для входа и выхода. Отсчёт прекращался после
проверки кода завершения и содержимого файла. Дефект считался обнаруженным,
когда программа возвращала 0, а вместо `values` появлялось поле
`is_symmetric`.

| Повтор | Время, мс |
|---:|---:|
| 1 | 209,2 |
| 2 | 183,2 |
| 3 | 185,4 |
| Среднее | **192,6** |

Значение относится к автоматизированному воспроизведению известного
дефекта, включая запуск программы и вычислительного процесса. Время
первоначального ручного обнаружения в этот замер не входит.
