# Баг-репорты ЛР № 4

## BR-01 Перезапись запроса при совпадении входного и выходного файла

- Версия: `21e02dd`.
- Среда: Windows, Git Bash, Python 3.11.6.
- Серьёзность: высокая, теряются исходные данные запроса.
- Приоритет: высокий, ошибка происходит при корректной матрице.
- Статус: исправлено.

### Шаги воспроизведения

Скопировать `examples/matrix_request.json` во временный каталог и передать
путь к копии в обоих аргументах:

```bash
demo_dir=$(mktemp -d)
cp examples/matrix_request.json "$demo_dir/request.json"
python src/main.py --input "$demo_dir/request.json" --output "$demo_dir/request.json"
```

**Ожидалось:** сообщение о совпадении файлов, код завершения 1,
входные данные сохранены.

**Получено:** код 0, содержимое запроса заменено ответом. Поля `dimension`
и `values` утрачены. Автоматический тест в
`tests/test_json_file_safety.py` до исправления завершился ошибкой
при сравнении содержимого файла.

### Исправление и проверка

В начале `run_json()` добавлено сравнение идентичности существующих файлов
через `Path.samefile()`. При совпадении возвращается код 1 с сообщением
«Файлы запроса и ответа должны различаться». Повторный запуск подтвердил
код 1, команда `cmp` подтвердила сохранность запроса. Сразу после правки
пройдены 36 тестов и 30 подтестов.
