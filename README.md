# Проверка симметричности матрицы

Программа предназначена для определения симметричности квадратной вещественной матрицы относительно главной диагонали.

## Требования к окружению

- Python 3.x
- Сторонние библиотеки не требуются

## Запуск программы

Запуск программы выполняется из корневого каталога проекта командой:

```bash
python src/main.py
```
